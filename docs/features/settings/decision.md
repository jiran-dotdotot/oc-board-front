## 정본 대조에서 뒤집힌 사실 주장

- **레거시 「공용 관리」 탭 삭제는 회귀가 아니다.** 정본은 공용 게시판을 게시판 관리 트리의
  고정 「공용」 노드로 흡수한다 → 가상 노드 `__public__` 으로 모델링.
- **레거시 `board/order.vue` 는 드래그가 아니다.** 클릭 선택 + ▲▼ + 스테이징 저장이며,
  비활성 버튼을 `invisible` 로만 숨겨 **클릭이 된다**. 유일한 레거시 DnD 는 `public.vue`.
- **정본 「폴더」는 별 엔티티가 아니다.** Go 는 카테고리 2단까지이고 `parent_category_id` 로
  옮길 수 없다 → 「폴더」 = depth 2 자식 카테고리.
- **`latest_post_type` · 메인 노출 게시판 슬롯 3개는 레거시에서 죽은 코드다**(템플릿 전체 주석,
  값만 write-only 로 되돌려 보냄) → 만들지 않았다.

## Go 배선 (전부 board 토큰 · `{S} = /api/v1/board/companies/{cid}/users/{uid}`)

| 동작              | 호출                                                       | 지킨 함정                                                                                                                                                                                     |
| ----------------- | ---------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 트리(회사 관리자) | `GET {S}/categories/admin` → `{public_boards, categories}` | 비활성 «공용» board 는 응답에서 빠지고 분류된 비활성은 들어온다                                                                                                                               |
| 트리(그 외)       | `GET {S}/categories/management` → **직접 배열**            | 봉투가 아니다. 공용도 없다 → `{public_boards: [], categories}` 로 감싼다                                                                                                                      |
| 상세 grant        | `GET {S}/boards/{id}` · `GET {S}/categories/{id}`          | 트리에 grant 가 없다 → 선택한 노드만 따로 조회                                                                                                                                                |
| 수정              | `PUT {S}/boards/{id}`                                      | **바뀐 필드만.** 추가 키 400 · `category_id`·`is_comment_alarm` 400 · non-DRIVE 가 `size_limit*` 키를 «이름만» 실어도 422 `BOARD_DRIVE_BOUNDARY`                                              |
| 추가              | `POST {S}/boards` · `POST {S}/categories`                  | 201 아니라 **200** · `category_id:null` = 공용(회사 관리자만) · 이미 자식인 부모 지정은 422 `CATEGORY_PARENT_IS_CHILD`                                                                        |
| 삭제              | `DELETE {S}/boards\|categories/{id}` → **204**             | 게시판 삭제는 **회사·카테고리 관리자만** — `can_manage` 로 게이트하면 board 관리자가 403 을 맞는다(`04:524`). 카테고리는 자식·게시판·게시글·자료까지 soft-delete → 확인 모달에 영향 범위 명시 |
| 정렬              | `PUT {S}/category-tree`                                    | **position 만** · 권한 밖/없는 ID 조용히 무시 · `reordered` 는 UPDATE 매치 수                                                                                                                 |

**부분 트리 위험을 답습하지 않았다.** 레거시 `order.vue:215` 는 부분 트리의 «인덱스+1» 로 전역
position 을 계산해 안 보이는 형제와 충돌한다. `positionPatch` 는 **기존 형제 position 값을
재배열**하고 **바뀐 항목만** 보낸다(`tests/settingsTree.test.ts` 에 부분 트리 케이스 있음).

## 접근성 (후퇴 금지)

탭 `role=tablist/tab` + `aria-selected`/`aria-controls` + ←→ 키 · 트리 `role=tree/treeitem` +
`aria-level`(깊이를 들여쓰기 밖으로) + `aria-selected` · **드래그의 키보드 대체 `Alt+↑/↓`** ·
스위치 `role=switch`+`aria-checked` · 라디오 `role=radio`+`aria-checked` · 비활성 사유는 **텍스트로도**
전달(색·opacity 단독 금지) · 정렬 결과는 `aria-live=polite`(드롭선이 색만으로 전달되므로).
