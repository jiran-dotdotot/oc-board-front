| 상세 grant        | `GET {S}/boards/{id}` · `GET {S}/categories/{id}`          | 트리에 grant 가 없다 → 선택한 노드만 따로 조회                                                                                                                                                |

## 고친 것 (이번 검증에서 실측으로 드러남)

- `총 {{total}}명` 이 **리터럴로 렌더**되고 있었다(트리거 라벨) → 키에서 `total` 제거(가정 12).
- `총 577명`(실제 496명) → `totalOf` 가 부서 인원수 합산이었다 → 덮이는 사용자 dedupe.
- 모달 `max-w-[94%]` 가 **뷰포트가 아니라 자기 자신의 720px 에 대해** 94% 로 풀려 카드가
  676.8px 로 렌더됐다(flex 아이템의 %는 내용 기반 containing block 에 걸린다) → `calc(100vw-2rem)`.
  같은 패턴이 `WriteScreen.tsx:364`(`max-w-[92%]`)에도 있다 — 그 모달은 이번 범위 밖이라 두었다.
- `<button>` 안에 `<button>`(체크박스) → 표시 전용 `CheckMark` 추가.
