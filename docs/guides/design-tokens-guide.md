## radius 램프 (2026-09-01 확정)

shadcn 기본은 `--radius`(0.5rem)의 calc 배수라 `4.8 / 6.4 / 11.2 / 14.4 / 17.6 / 20.8px` 같은
**스케일 밖 값**을 만든다. `src/index.css` 에서 정본 값으로 덮어썼다.

| 클래스 | px | 역할 |
|---|---|---|
| `rounded` | 4 | 뱃지 |
| `rounded-md` | 8 | **컨트롤** (버튼·인풋·칩·아이콘버튼) |
| `rounded-lg` | 12 | 카드·패널·드롭다운 |
| `rounded-xl` | 16 | 모달 |
| `rounded-2xl` | 20 | 필 |
| `rounded-full` | — | 원형·캡슐 |

`rounded-sm` · `rounded-3xl` · `rounded-4xl` 은 **사용 금지** (정의하지 않는다).
⚠️ 이 변경으로 `rounded-lg` 가 8px → **12px** 로 바뀌었다. 기존에 «컨트롤» 의도로 쓰던
`rounded-lg` 는 `rounded-md` 로 옮겨야 한다.

## 아이콘 · 자간 · 행간 (2026-09-01 신설)

정본표에 없어 판정 근거가 없던 3개 스케일을 새로 정했다.

**아이콘** — `12 / 14 / 16 / 20 / 24 px` (`size-3` `size-3.5` `size-4` `size-5` `size-6`),
stroke-width **1.7 ~ 2.2**.

아이콘이 «아닌» 것은 이 스케일을 적용하지 않는다 — 아바타, 아이콘버튼 히트영역,
체크박스/라디오/토글 컨트롤 상자, 파일 확장자 태그, 썸네일, 스켈레톤, 로고 마크.
같은 `size-[Npx]` 값이 아이콘과 컨테이너에 섞여 쓰이므로(예: `size-[15px]` 가 아이콘이자
자료실 체크박스) **`<svg …>` 여는 태그 안쪽만** 스케일 대상이다.

**예외 (사용자 확정 2026-09-01)**

| 대상 | 값 | 이유 |
|---|---|---|
| 일러스트 글리프 — 빈 상태·이미지 자리표시(`ImageIcon`) | `26` `34` `44` | 아이콘이 아니라 «일러스트». 26px 이상은 스케일 밖으로 본다 |
| 로딩 스피너 | `30`, stroke `3` | 글리프가 아니라 원의 굵기 |
| 체크박스·라디오의 체크마크/대시 | stroke `3.4` | 12~16px 작은 상자 안에서 두꺼워야 보인다 |

`npm run check:scale` 이 위 예외를 알고 있고, 나머지는 실패시킨다.
